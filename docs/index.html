Quick start

第一次只要三步驟

以下使用 Windows PowerShell。每台電腦只需安裝一次，之後可直接請 Agent 協助。

1

下載並安裝

取得專案，安裝瀏覽器自動化與 PDF 截圖工具。

git clone https://github.com/mathruffian-dot/wordwall-cli.git
cd wordwall-cli
.\setup.ps1 -WithPdf
2

登入自己的帳號

會開啟瀏覽器，由你本人登入；Agent 不會看到密碼。

python wordwall.py login
python wordwall.py check
3

直接說出需求

例如：「把十題整數運算做成 Quiz，先預覽。」

python wordwall.py doctor --login --pdf

Safe workflow

每次建立，都有安全檢查點

工具不會一收到題目就直接發布。先把內容與圖片檢查清楚，再由你決定是否建立真實活動。

老師保有最後決定權

「預檢」只驗證資料；「編輯器預覽」會填入 Wordwall，但不按 Done。看到內容正確後，才執行正式建立。

✓ 最小風險流程
01

說明需求

年級、主題、題數、遊戲方式，以及是否使用圖片。

02

規劃範本與素材

選擇 Quiz、配對、分類、轉盤，並判斷純文字、截圖或 AI 圖片。

03

本機預檢

檢查題目 JSON、正解與圖片路徑，不建立活動。

--dry-run
04

線上編輯器預覽

填入 Wordwall 並回讀內容，但不按 Done。

--editor-check
05

確認後正式建立

核對名稱、題目、圖片、選項與正解，再建立真實活動。

Question levels

題目圖片，選擇剛剛好的方法

不是每題都需要 AI 生圖。工具採用最低足夠層級，兼顧精準度、版面與創意。

Level 1

純文字出題

題幹、選項與答案都能清楚用文字呈現。

  • 語文與知識問答
  • 基本計算
  • 單字、定義與分類
例：(-3) + 8 = ?
Level 2

截圖／精準圖形

既有題庫、PDF、幾何、座標圖與統計圖。

  • PDF 題本裁切
  • 題目與圖形選項合成
  • 精準數學圖形
例：截取幾何題，選項使用 A／B／C／D。
Level 3

AI 生成圖片

傳統考卷或精準繪圖難以做到的視覺創意。

  • 漫畫故事與角色抉擇
  • 視覺解謎、遮擋與找錯
  • 多視角與狀態變化
例：四格漫畫中，哪個線索能破解密碼？

Examples

照著範例，就能開始

切換情境，看看可以怎麼對 Agent 說，以及工具會執行哪些步驟。

建立文字選擇題

適合從現有題目或教師口述內容開始。

你可以這樣說

「幫我做五題八年級整數運算 Quiz，四選一，先預覽不要發布。」

{
  "template": "quiz",
  "title": "整數運算練習",
  "items": [{
    "question": "(-3) + 8 = ?",
    "answers": ["-11","-5","5","11"],
    "correct": 2
  }]
}
python wordwall.py create `
  --content "examples\quiz_example.json" `
  --dry-run

python wordwall.py create `
  --content "examples\quiz_example.json" `
  --editor-check --headless

把 PDF 題本做成圖片題

保留幾何圖、數學符號與原始版面。

你可以這樣說

「把 PDF 第一到第五題裁成圖片，題目和圖形選項放在同一張圖。」

python wordwall.py pdf-screenshot `
  --input "C:\題本\數學題本.pdf" `
  --page 2 `
  --crop "55,75,540,215" `
  --output "assets\questions\q01.png"
{
  "question": "請看圖作答",
  "image": "q01.png",
  "answers": ["A","B","C","D"],
  "correct": 1
}

下載學生作答成績

先列出作業，再預檢下載目標；確認後才下載學生資料。

你可以這樣說

「列出八年級幾何的作業，不顯示姓名；確認後下載成 Excel。」

python wordwall.py results list `
  --title "八年級幾何" `
  --headless
python wordwall.py results export `
  --assignment-id 123456 `
  --format xlsx `
  --dry-run --headless

# 確認後移除 --dry-run

Templates

文字、圖片、配對與分類，都有適合範本

Agent 會依需求與媒體型態，推薦目前已實測支援的範本。

Quiz 家族選擇題、迷宮、飛機
Match up文字、圖文、圖配圖
Group sort概念與圖片分類
Matching pairs兩種翻牌模式
Random wheel隨機抽題與任務
True or false是非快速判斷
Complete sentence句子填空
Labelled diagram底圖標籤定位
⌾

帳號與學生成績，留在正確的地方

本工具不索取密碼。登入由本人完成，session 留在自己的電腦；成績預設下載到 Downloads，不應放入 GitHub。
