# 三級出題與視覺素材工作流

WoWo CLI 採「能用低等級完成，就不升級」原則。素材等級不是品質高低，而是製作方式與風險不同。

## 第一級：純文字出題

適合定義、運算、概念判斷、文字分類、文字排序及不依賴版面的題目。
直接使用 Wordwall 文字欄位，不產生圖片。

## 第二級：截圖出題

適合既有考卷、題庫、PDF、精準幾何圖、座標圖、統計圖、函數圖，以及版面不能跑掉的題目。

- 題幹與圖片選項必須共同判讀時，全部排成一張定稿 PNG。
- Wordwall 選項只放 `A/B/C/D`，避免平台重新排版圖片選項。
- 圖片配對先完成左右端素材，再各自截圖定稿後放入 Pair JSON。
- 精準線段、角度、刻度、座標與公式不得交給生成式圖片模型猜測。

## 第三級：AI 生成圖片出題

只有傳統考卷、截圖或精準繪圖難以表達的視覺敘事才使用。公開 repo 預設使用
ChatGPT 訂閱方案內建生圖；目前維護者本機操作可依明確設定使用 `draw` 技能。

可發展的題型包括：

1. 漫畫分鏡推理：根據角色行動、前後畫面或遺漏的一格作答。
2. 視覺解謎與密碼：從場景物件、數量、位置或規律找線索。
3. 多視角空間推理：俯視、側視、第一人稱或不同角色看到的畫面。
4. 遮擋與隱藏結構：只露出部分物件，推論完整形狀、數量或排列。
5. 影子、倒影與光線：判斷光源、鏡像、方向或時間變化。
6. 狀態變化與因果：比較故事前後、物件變形、流程階段或下一幕。
7. 視覺找錯與反例：找出不合理場景、錯誤量感或違反規則的物件。
8. 奇幻與不可實拍場景：太空、微觀、擬人、未來世界中的數學任務。
9. 情緒與非語文線索：從表情、距離、肢體或合作關係讀取資訊。
10. 虛構文件資料判讀：任務地圖、票券、菜單、收據、儀表板或海報。
11. 尺度與估測：巨人視角、微縮世界、容量、距離或比例感判斷。
12. 規則世界與反例探索：改變一條數學規則後，判斷哪些現象仍成立。

### AI 必要性門檻

以下需求預設不通過第三級：一般三角形、座標平面、統計圖、函數圖、尺規作圖、精確比例或公式圖。
如果創意場景同時包含精準數學元素，採「AI 情境底圖＋傳統精準覆圖」混合流程。

## 定稿與素材 manifest

不論第二或第三級，都要保存來源、定稿 PNG 與品質覆核。`plan --assets` 會檢查：

- `math_verified=true`
- `answer_leak_checked=true`
- `mobile_checked=true`
- `capture_finalized=true`
- 第三級必須保存實際 prompt 與生圖方式
- 整張題圖模式必須有 `role=composite-question`

範例見 `examples/asset_manifest_screenshot.json`。

## CLI 流程

```powershell
python wordwall.py plan --request "幾何圖形選擇題，選項只能用圖片判別"

python wordwall.py plan `
  --request "幾何圖形選擇題，選項只能用圖片判別" `
  --content examples\image_quiz_example.json `
  --assets examples\asset_manifest_screenshot.json
```

兩項預檢通過後，再執行 `create --editor-check`；仍須等待使用者確認才正式建立。
